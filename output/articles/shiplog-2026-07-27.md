## x402aff: the affiliate kit goes live

The week's dominant story. `MiroShark/x402aff` — the on-chain affiliate kit for MiroShark — got fully productized in this window: renamed, packaged, published, and wired end-to-end into the website.

**Kit side (14 PRs):**

- **Rename → x402aff** ([#14](https://github.com/MiroShark/x402aff/pull/14)) — project gets its proper name
- **Python installable package** ([#20](https://github.com/MiroShark/x402aff/pull/20)) — `pip install x402aff`
- **`aff.splits_payload()`** ([#17](https://github.com/MiroShark/x402aff/pull/17)) — reusable data endpoint for dashboard, available in both Python and TypeScript
- **v0.1.1 published** to PyPI + npm ([#23](https://github.com/MiroShark/x402aff/pull/23), [#24](https://github.com/MiroShark/x402aff/pull/24), [#27](https://github.com/MiroShark/x402aff/pull/27)) — badges added, classifiers declared
- **Security verification** ([#15](https://github.com/MiroShark/x402aff/pull/15)) — cache fix, adversarial split tests, security docs

**Website side (~20 PRs on aaronjmars/miroshark-website):**

- **Live permissionless claims dashboard** at `/x402aff` ([#155](https://github.com/aaronjmars/miroshark-website/pull/155), [#167](https://github.com/aaronjmars/miroshark-website/pull/167)) — proxies the kit endpoint; real on-chain split params + RPC rate-limit resilience
- **Builder split live** ([#166](https://github.com/aaronjmars/miroshark-website/pull/166)) — `/sim` runs now route 10% to builder split `bc_c12702g2`
- **x402aff discovery marker** ([#165](https://github.com/aaronjmars/miroshark-website/pull/165)) — stamped on every payment for ecosystem-wide tracking
- **Off-chain `?ref=` referral deprecated** ([#160](https://github.com/aaronjmars/miroshark-website/pull/160)) — consolidated on the on-chain x402aff kit
- **Marker-wide index** ([#176](https://github.com/aaronjmars/miroshark-website/pull/176)) — every kit split, not just MiroShark's, surfaced in the dashboard
- **Plain-language x402 docs** ([#177](https://github.com/aaronjmars/miroshark-website/pull/177)) — kit documented inside the x402 section
- `/x402` merged into `/docs` with redirect ([#161](https://github.com/aaronjmars/miroshark-website/pull/161))

The full x402aff push: 34 PRs in 4 days to take this from internal splitter to a documented, installable, published kit with a live claims UI.

## Aeon: multi-harness + Claude 5

Aeon expanded from Claude Code–only to a multi-harness setup. Several architecture changes landed:

- **Multi-harness support** ([#765](https://github.com/aeonfun/aeon/pull/765)) — Codex, Pi, Vibe, and Kimi added as harness options alongside Claude Code. AGENTS.md now mirrors the full CLAUDE.md per run ([#770](https://github.com/aeonfun/aeon/pull/770))
- **Claude 5 family default** ([#775](https://github.com/aeonfun/aeon/pull/775)) — Claude 5 Sonnet as the default model; older model IDs removed
- **aeon-doctor linter** ([#761](https://github.com/aeonfun/aeon/pull/761)) — static config-correctness checker; catches bad skill config before a run fires
- **Grok OAuth rotation fix** ([#773](https://github.com/aeonfun/aeon/pull/773)) — rotated refresh token now persisted; GROK_CREDENTIALS survive past the 6h window
- **Run banner fix** ([#769](https://github.com/aeonfun/aeon/pull/769)) — names the resolved harness model, not the config default
- **Dashboard: per-skill model picker** ([#766](https://github.com/aeonfun/aeon/pull/766)) — tracks active harness; MCP controls disabled on Codex harness ([#771](https://github.com/aeonfun/aeon/pull/771))
- **Secret rename** ([#774](https://github.com/aeonfun/aeon/pull/774)) — `MCP_SECRETS_PAT` → `GH_SECRETS_PAT`, standardized for MCP + Grok
- **Six-harness setup documented** ([#767](https://github.com/aeonfun/aeon/pull/767)) — README + aeon.yml updated; /aeon setup skill shipped in-repo ([#762](https://github.com/aeonfun/aeon/pull/762))
- **OKF CI scoped** ([#777](https://github.com/aeonfun/aeon/pull/777)) — trigger only on markdown changes under OKF roots; less noise
