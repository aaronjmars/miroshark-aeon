# Miroshark Shiplog — Sept 28 → Oct 1

Window: **2026-09-28 → 2026-10-01** (3 days, since the last shiplog run).

## The bytes

**x402 discovery push.** The headline thread this window is getting MiroShark's `x402` payment endpoint found by other agents, not just built.

- **PayAI Bazaar listing shipped (09-29, [MiroShark-x402#261](https://github.com/aaronjmars/MiroShark-x402/pull/261), private repo).** PayAI only catalogs payments settled through its own facilitator, and prod settles through CDP — so this is a standalone tool that signs one Base USDC payment in-browser and posts it straight to PayAI's `/settle`, just to get `POST /run` listed. Verified with a real on-chain settle (`admitted_by_settlement`). Two follow-up fixes the same day: `MiroShark-x402#260` (bazaar declaration schema) and `MiroShark-x402#259` (404 vs 401 on the public API gate). Result landed publicly today — see traction below.
- **x402aff 0.3.1 shipped (09-30, [x402aff#41](https://github.com/MiroShark/x402aff/pull/41)).** Packages now point at `www.x402aff.xyz`, and the release adds an installable agent skill (`skills/x402aff/SKILL.md`) — any agent can wire the affiliate kit into its own x402 seller with `npx skills add MiroShark/x402aff`. Two follow-up PRs (`#42`, `#43`) swapped the README art for the new site's banner/infographics.
- **MiroShark/MiroShark#313** added x402aff to the engine's own ecosystem registry (`ECOSYSTEM.md` + `ecosystem_catalog.py`) — 13 lines, docs/metadata only, not engine code.

**Website work (`miroshark-website`, 10 merged PRs 09-29→09-30).** Mostly surface area for the above: the Hugging Face dataset now links across the site (`#364`), the x402aff page got its own headline + logo (`#363`), an SEO link-out to x402aff.xyz (`#362`), GA4 instrumentation (`#361`), a webmcp hardening fix (abort signal, throw-on-failure, `#358`), and the affiliate "All sellers" tab now points at the kit's own dashboard (`#366`). One real bug fix in the stack: the video parser was crashing on zero-count rounds and unscored posts (`#365`).

**Engine repo, still quiet.** `MiroShark/MiroShark` logged 4 commits this window — 3 are dependency bumps (`#312`, `#314`, `#315`), the 4th (`#313`) is the registry addition above. That's the engine repo's 5th straight shiplog window without a real engine-code PR (the simulation runner, agent loop, cost pipeline haven't moved since this thread started in August). The actual engine work keeps landing in the private `MiroShark-x402` companion repo instead — same pattern flagged in the 09-07 and 09-21 digests, still unresolved as an open question for the operator: upstream more of it into the public repo the stars/ecosystem metrics read off of, or accept the split.
