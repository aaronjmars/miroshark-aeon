# Shiplog — Sep 21 → Sep 28

**By the numbers (operator-wide, for scale):** 130 PRs opened, 124 merged, across 19 repos. **MiroShark-tagged repos merged 42 PRs this window.** MiroShark stars: **1,457 (+5)**. Forks: **300** (no baseline in this tracker yet — starts next window).

## The proof: sim conversations, published as a dataset you can audit

On 09-25 `@aaronjmars` dropped a public HuggingFace dataset — 8,201 decisions from `@miroshark_` simulations, linking what an agent saw, what it reasoned, and what it did (a post, a quote, a follow, or a YES/NO trade on the prediction market). Same day, a follow-up post framed the actual thesis: pairing a tweet with a trading action is one of the most underexplored primitives in AI x crypto, and this is a first pass at translating narrative into a price move on a prediction market. `MiroShark/MiroShark` shipped the matching receipt — PR #311 links the dataset from the README. `miroshark-website` followed with a blog post (#356) and `miroshark-aeon`'s own changelog run tagged it "the lone substantive change" in a light week.

This is the "never present a simulation as ground truth" constraint made literal: instead of another "look what we simulated" post, it's the raw decision log, public, checkable.

## The ecosystem push: an open PR to become a default Solana skill

`aaronjmars` opened `solana-foundation/pay-skills#263` — "Add MiroShark simulation provider" — on 09-21, proposing MiroShark as an x402-metered listing (`FQN: miroshark/simulation`, category `ai_ml`, flat $1/run in USDC, live 402 challenge advertising Solana + Base + Monad). Seven days in: one automated Greptile review, `MERGEABLE`, no human maintainer review yet. Unmerged, but this is exactly the "$1 to simulate anything" pitch aimed straight at the audience that would actually spend the dollar — worth watching, not yet a win.

## The bytes nobody sees: 22 PRs of x402 + memory + observability hardening

`MiroShark-x402` (private) merged 22 PRs this window, clustered in three places:
- **Payment hardening** — per-run cancel tokens resistant to spoofed client IPs on public cancel (#246), paid runs only start after settlement with an SSRF-guarded `callback_url` and no pre-settle LLM fetch (#245).
- **Sim-memory discipline** — "wonderwall" got a hard per-call wall-clock cap with re-issue on sim model calls (#254), kept tool-call/result pairs intact so tool-memory pruning actually works (#248), and two review-nit passes tightened both (#251, #252).
- **Observability** — Langfuse now records which OpenRouter provider served each generation (#256), splits and corrects generation names, fixes dead review-queue keys (#253), and time-bounds/paginates the review-queue v2 query (#247) — the trace layer that makes a sim run auditable after the fact, not just at report time.

Smaller but real: routing now prefers Xiaomi for mimo calls after DeepInfra proved out at 6-7 tok/s (#250), a new `agent_error_rate` / `top_agent_error` run score (#249), and a vertical 9:16 video export option with real stat counts in the copied report (#241, #243) — shipped in parallel on `miroshark-website` (#347).

`miroshark-website` merged 12 PRs — wallet UX (grouped top-up popup, shorter balance lines, $MIROSHARK holdings shown in the account menu: #348-#353), a `/highlights` sticker board, `cancel_token` + token-gated `/cancel` docs (#355), and the dataset blog post above. `miroshark-bench` merged 6 — migrated off the deprecated Langfuse observations v1 endpoint (#16), added concurrent turn-latency replay with real p50/p95 (#14), and ran a persona web-research + generation pass (#15).
